# 决策摘要

- **定位：**单用户 AI 增强型备考系统，P0 范围为 FR-001 至 FR-014。
- **关键取舍：**① 无注册登录、可选访问口令；② AI 助手直接进 P0（用户即 owner，有引用与边界机制兜底）；③ 自托管后端为推荐存储方案，纯前端本地为降级备选。
- **明确不做：**多用户与社交、课程内容生产分发、原生 App。
- **最可能反转结论的假设：**部署形态与 AI API 选型（待确认 A-1 / A-2）。
- **第一阶段验证门：**连续 4 周计划完成率中位数 ≥ 30% 且复习队列日均完成稳定 → 进入 P1；否则回到 FR 范围诊断，不堆功能。

# 产品目标与非目标

## 产品目标（可观测）

- **G1 冷启动：**首次部署到生成第一份可执行计划 ≤ 30 分钟（初始参数，受大纲导入与资料上传速度影响）。
- **G2 周循环：**连续 4 周每周完成一次「学习报告 → 调整下周计划」。
- **G3 AI 增强：**知识库覆盖本考试核心知识点 ≥ 80%（联网搜集 + 人工确认入库）。

## 非目标（本期不做）

- **多用户、注册登录、社交：**本人自用，不引入用户体系。
- **课程内容生产与分发：**知识库只收上传与搜集内容，不生产原创课程。
- **对外共享与协作：**数据仅本人可见，导出自留。
- **原生 App：**P0 仅响应式 Web。

# 关键产品决策

**存储与部署（2026-09-20 更新，随 A-1/A-4 确认）：**推荐**轻量自托管后端——单容器（Docker）+ SQLite + 本地文件目录**。理由：① 大模型与 Tavily 的 API Key 必须放服务端，纯前端（静态站 + IndexedDB）会把 Key 暴露在公网页面里，任何人抓包即可盗刷；② FR-005 的网页链接抓取正文需要服务端代理解决跨域，纯前端无法实现；③ 大 PDF 解析、OCR 属耗时任务，需要服务端后台化，避免浏览器标签页关闭即中断。资料规模适中（A-4 已确认），SQLite + 本地盘完全够用，无需独立数据库/对象存储。**三档部署路径（任选其一）：**家用闲置设备 + Tailscale/frp 内网穿透（0 元，免备案，推荐有旧电脑/NAS 时首选）；阿里云轻量 2核2G 40G 盘秒杀款约 ¥38/年 或 ECS e实例 ¥99/年（新老同享、续费同价）；腾讯云轻量 2核4G5M ¥188/年。注意：大陆云服务器绑域名需 ICP 备案，备考 8 个月周期内若想省事，家用设备方案或用 IP+端口直接访问可绕开。访问口令（FR-001）三档均保留。

**AI 接入：**外部大模型 API + 联网搜索 API（候选见待确认 A-2），全部调用记录用量与成本；发给模型的内容按所选 API 政策处理，不替 API 承诺「不用于训练」。**成本量级（2026-09 核价，个人自用按每天约 20 次调用、月输入约 240 万 / 输出约 50 万 tokens 估算）：**DeepSeek V4-Flash 原厂约 6 元/月，豆包 1.6-flash 约 1 元/月，阿里百炼 deepseek-v3.2 约 6 元/月——正常使用月成本 1\~6 元，属可忽略项；联网搜索 Tavily 免费档每月 1000 次调用，个人搜集场景基本 0 成本。**全程零成本路径（2026-09-20 用户确认只用免费档，据智谱官方定价页）：**文本统一用智谱 GLM-4.7-Flash（200K 上下文，输入/输出/缓存全免费，OpenAI 接口兼容、手机号注册、国内直连），图片 OCR/视觉理解用智谱 GLM-4.6V-Flash（同样免费），配 Tavily 免费档即可实现完全 0 元——上述月调用量对免费档的速率/并发限制而言余量充足（具体限额以控制台「额度/财务」页为准）。因此 R-3「成本失控」的实际风险很低，成本意识重点防异常用量（如失控循环调用），正常使用无需限额焦虑；免费政策若调整，回 A-2 重审换型。

- **激励三边界：**① 不打断主路径（无弹窗强提醒）；② 奖励与真实行为绑定（打卡 = 真实专注时长）；③ 可关闭（动效与声音在设置中可关）。

# AI 助手：安全边界与引用机制（专项）

引用、规则推理、安全边界三项是产品级硬约束，设计要点如下，完整流程见业务流程图 B。

- **引用机制：**本地来源标注资料名 + 页码/段落（点击跳原文）；联网来源标注 URL + 访问日期；无可追溯来源时显式标注「无来源依据，仅为模型生成」；提供「来源不符」反馈入口。
- **规则推理：**结构化问题（大纲、错题分布、薄弱点）按「依据 → 规则 → 结论」三段式展示，结论可下钻到原始数据；口诀、类比、费曼提问等生成内容标注「AI 生成、非权威」。
- **安全边界（三条红线）：**① 资料未覆盖必须声明，禁止编造权威结论；② 不出现「押题」「保过」话术，预测类回答必须给不确定性说明；③ 生成内容带「AI 生成」标识，联网资料仅自用、导出保留来源。
- **降级：**AI 不可用时核心学习功能（计划、做题、复习、笔记、计时）离线可用。

# 状态机

- **任务状态（FR-003 / FR-004）：**待办（初始）→ 进行中（启动计时）→ 已完成（打卡，当日可撤销一次）；已逾期（每日扫描标记）；已跳过（显式放弃的终态；逾期默认顺延，可改跳过）。
- **错题掌握状态（FR-009）：**未掌握（首次入本，进调度）→ 复习中（复习至少一次且正确）→ 已掌握（连续两次正确，可手动回退）。

# 功能需求（P0）

每项 FR 含用户故事、规则与行为、验收标准（AC-{FR}-{序号}，每项 FR 一条成功路径 + 一条边界/异常路径，共 28 条）。三张业务流程图先给全局，再看单点规则。

## FR-001 单用户模式与数据底座

**用户故事：**作为站长，我希望部署即用，无需注册，所有数据属于我，可以一键备份。

- 首次启动进入引导（考试设置 + 大纲导入 + 资料上传），不要求账号信息。
- 可选访问口令：默认关闭，开启后进入站点需输入（哈希存储、可随时关闭）。
- 数据模型：考试 → 科目 → 章节 → 知识点 → 任务 / 题目 / 错题 / 笔记。
- 备份：一键导出 JSON（结构化）+ Markdown（笔记与资料）压缩包；导入支持跨设备迁移；结构不兼容时明确提示并保留原数据。
- AC-001-1（成功）：给定首次部署，当访问站点，则直接进入引导流程，不出现任何注册登录页。
- AC-001-2（边界）：当开启访问口令后访问未输入，则拦截跳转口令输入页，错误 3 次提示等待 60 秒。

## FR-002 学习驾驶舱

**用户故事：**我希望打开网站一眼看到今天做什么、距考试还有多少天、近期节奏。

- 顶部：考试倒计时、连续打卡天数、今日专注时长累计。
- 中部：今日任务清单（按科目分组）+ 待复习队列提示。
- 下部：近 12 周学习热力图 + 快捷入口（开始专注 / 开始做题 / 问 AI）。
- 边界：无考试目标时显示创建引导；首周热力图按实际天数渲染并提示样本不足。
- AC-002-1（成功）：给定考试日期 90 天后、连续打卡 7 天、今日 3 个任务完成 2 个，则驾驶舱正确展示三个指标。
- AC-002-2（边界）：给定新用户仅注册 3 天，则热力图显示 3 格并注明「样本不足 12 周」。

## FR-003 计划中心

**用户故事：**我希望导入考试大纲，让系统帮我把大纲变成可执行的计划。

- 大纲导入：粘贴文本 / 上传文件 → AI 解析为科目-章节-知识点树 → 预览确认 → 入库（流程图 A 第 ① ② 列）。
- 任务生成：输入每科每周可用天数与每日时长，均匀排期到考试日期前（P0 不做智能排课），可拖拽改期、批量顺延。
- 逾期处理：每日 0 点（用户时区）扫描，默认顺延到当日；周日晚自动生成调整建议，人工确认生效。
- 边界：解析失败给出原因（格式不支持 / 内容过短）并保留原文；计划日期超出考试日期保存被拦截。
- AC-003-1（成功）：给定用户粘贴大纲文本，当 AI 解析出 3 科目 20 章节，则预览页正确展示树形结构，确认后入库。
- AC-003-2（边界）：给定大纲文本仅 5 个字符，则解析失败并提示内容过短，原文保留供手动补充。

## FR-004 专注模式

**用户故事：**我希望开启任务时进入沉浸的全屏专注界面，用计时器保证专注度。

- 番茄钟：默认 25 分钟专注 + 5 分钟休息，可选 15 / 25 / 45 分钟档，连续轮数上限 8 轮（初始参数）。
- 沉浸界面：暗色全屏，显示任务名、倒计时、本日已完成轮数，可一键退出。
- 边界：计时中关闭页面弹窗说明将丢本轮记录；暂停超 30 分钟视为放弃，不累计时长。
- AC-004-1（成功）：给定任务 A 进入专注模式 25 分钟，当倒计时结束，则本轮 25 分钟写入任务 A，且专注界面正确切换至休息提示。
- AC-004-2（边界）：当用户在专注进行中点击退出并确认，则本轮不写入任务用时，任务状态不变。

## FR-005 知识库与资料管理

**用户故事：**我希望把教材讲义、截图、网页链接统一放进知识库，让 AI 基于它们回答问题。

- 支持上传：PDF、Word、Markdown、纯文本、图片（OCR）；网页链接自动抓取正文。
- AI 整理：自动提取标题、识别主题、按科目-章节归档（可调整）；联网搜集结果同归此处（流程图 B 路径 1、2）。
- 检索：全文检索（标题 + 正文），按科目筛选，展示资料名、定位、归档科目。
- 边界：解析失败保留原文件并提示；OCR 失败可重试；容量上限按 A-4 校准。
- AC-005-1（成功）：给定用户上传 1 个 PDF 教材，当 AI 完成解析，则该资料出现在知识库列表，标题、归档科目、页数自动填入。
- AC-005-2（边界）：当上传损坏的 PDF 文件时，解析失败提示原因，原文件保留供手动处理。

## FR-006 联网资料搜集

**用户故事：**我希望 AI 帮我按大纲搜集资料整理入库，省去手工搜集时间。

- 触发：AI 助手输入「搜集关于 X 的资料」或知识库点「联网搜集」。
- 流程：AI 搜索 → 去重与可信度排序 → 候选清单（标题 + 来源 URL + 摘要）→ 勾选确认 → 入库（流程图 B 路径 2）。
- 边界：搜索失败显示具体错误，可换关键词；候选清单不自动入库，必须用户确认。
- AC-006-1（成功）：给定用户触发「搜集关于长期股权投资的资料」，当 AI 返回 10 条候选，则清单正确展示来源与摘要，勾选 5 条后入库。
- AC-006-2（边界）：当联网搜索 API 超时或不可用，则明确提示失败原因，不自动重试超过 2 次。

## FR-007 AI 备考助手

**用户故事：**我希望直接和 AI 对话答疑、生成口诀和解释，且每个回答有据可查。

- RAG 问答：基于知识库，可选补充联网；每条回答附引用（点击跳原文）；顶栏标注「AI 生成 · 基于知识库/联网」（流程图 B 下段）。
- 学习辅助生成：「生成记忆口诀 / 用类比解释 / 费曼式反问」三类快捷指令，结果一键存笔记。
- 模式可选：「仅本地 / 仅联网 / 本地+联网」；会话可中断重开。
- AC-007-1（成功）：给定知识库有「长期股权投资」章节资料，当用户提问「权益法与成本法的核心区别」，则回答包含对比并附 2 条引用（资料名+段落）。
- AC-007-2（边界）：当知识库与联网均无相关内容时，回答显式声明「资料未覆盖，仅为模型生成」，不做权威口吻。

## FR-008 题库与做题模式

**用户故事：**我希望有题库做真题、模拟题，做错的自动进错题本。

- 题目来源：手动创建、批量导入（Excel/CSV/JSON）、AI 按知识点生成；字段为题干、选项、答案、解析、知识点、难度。
- 做题模式：按知识点单题练习、按章节组卷模考（题数时长自定义）、错题重做；客观题自动判分，主观题标记待人工判（流程图 C 上段）。
- 边界：题干相似度超阈值时创建需确认；删除题目时确认是否连带删错题记录。
- AC-008-1（成功）：给定用户生成 10 道关于「长期股权投资」的单选，当进入组卷并开始，则题目顺序与计时正确开始。
- AC-008-2（异常）：当用户在客观题作答错误时，题目自动入错题本且记录错误次数为 1。

## FR-009 错题本与间隔重复复习

**用户故事：**我希望错题按科学节奏复习，不用自己记哪天该重做。

- 错题入本：FR-008 自动入本 + 手动录入；错因标签（概念混淆 / 计算失误 / 审题偏差 / 记忆遗漏 / 其他）+ AI 归因建议（可改）。
- 间隔重复：简化 SM-2，序列 1 → 3 → 7 → 14 天，答对延长、答错重置为 1 天；连续 2 次正确转已掌握（流程图 C 下段含示例）。
- 每日复习队列在驾驶舱提示；复习反馈支持「答对 / 答错 / 不确定」，不强制二选。
- AC-009-1（成功）：给定错题首次入本 1 天后，当到达复习日期，则该题出现在今日复习队列顶部。
- AC-009-2（边界）：当用户在复习中选择「答错」，则复习间隔重置为 1 天，掌握状态回到未掌握。

## FR-010 笔记

**用户故事：**我希望用 Markdown 写笔记，AI 整理的内容一键保存，并关联知识点和错题。

- 编辑器：基础 Markdown（标题、列表、表格、公式、任务列表）+ 实时预览。
- AI 整理：对话片段「整理到笔记」，生成结构化版本（标题、要点、关联知识点）。
- 关联：笔记可手动或自动关联知识点 / 错题，双向可见；取消关联提供级联选项并二次确认。
- AC-010-1（成功）：给定用户在 AI 对话中选中一段解释，当点击「整理到笔记」，则生成结构化笔记保存到默认科目，关联对应知识点。
- AC-010-2（边界）：当用户取消关联错题时，提供级联选项并明确告知后果，二次确认后执行。

## FR-011 模考记录与成绩趋势

**用户故事：**我希望记录每次模考成绩并看到趋势，了解进步曲线。

- 录入：手动录入（日期、科目、得分、满分、备注）或组卷一键落档；按科目生成趋势折线。
- 对比：选定两次模考横向对比（分数差、知识点覆盖差）。
- 边界：得分超满分拦截；删除记录二次确认。
- AC-011-1（成功）：给定用户录入 3 次模考，当打开模考记录页，则各科趋势折线展示 3 个数据点。
- AC-011-2（边界）：当用户输入得分超过对应满分，则保存被拦截并提示。

## FR-012 学习报告

**用户故事：**我希望每周看到一张完整报告：数据、AI 总结与下周建议。

- 周报：本周专注时长、计划完成率、首次作答正确率、错题掌握变化、薄弱知识点 Top 5、AI 总结与下周建议；每周日晚自动生成，历史归档。
- 阶段报告：每月末生成本月 vs 上月对比 + AI 阶段复盘。
- 边界：数据不足 7 天标注样本不足；AI 总结失败时只展示数据部分并明示。
- AC-012-1（成功）：给定用户本周有数据，则周报卡片正确展示五项数据指标与 AI 总结（基于真实数据生成）。
- AC-012-2（边界）：给定 AI 助手不可用，则报告展示数据部分且明示「AI 总结暂不可用」。

## FR-013 激励与游戏化体验

**用户故事：**我希望备考过程有点成就感与乐趣，不那么枯燥。

- 连续打卡：每日完成至少 1 个专注轮即打卡；连续 7 / 30 / 100 天解锁徽章。
- 成就徽章：百题斩（累计 100 题）、错题清零、周冠军、大纲全覆盖等。
- 进度可视化：章节地图进度条 + 热力图 + 每日一句（可关闭）。
- 边界：激励不打断主路径、不弹窗强提醒；动效与声音可一键关闭。
- AC-013-1（成功）：给定用户连续 7 天每日完成至少 1 个专注轮，则驾驶舱顶部显示「连续 7 天」并解锁徽章。
- AC-013-2（边界）：当用户在设置中关闭激励动效与声音，则所有徽章解锁动画与提示音不再出现。

## FR-014 数据备份与隐私

**用户故事：**我希望随时导出所有数据，也能在不想用时一键清除。

- 导出：JSON（结构化）+ Markdown（笔记资料）+ 资料原件压缩包，含 README 与时间戳。
- 导入：全量恢复用于跨设备迁移；冲突时提供「合并 / 覆盖」选项。
- 清除：二次确认 + 5 秒等待，执行后不可恢复；另有单独「清除 AI 缓存与会话」入口。
- AC-014-1（成功）：给定用户点击「导出全量数据」，则生成压缩包并下载，含全部结构化数据与资料原件。
- AC-014-2（边界）：当用户执行「清除全部数据」时，二次确认加 5 秒等待后方可生效，执行后不可恢复。

# 学习报告数据口径与自用健康度

- **学习时长：**专注计时自然结束的轮次时长 + 做题停留时长（去掉切走超 2 分钟的离场段）。
- **计划完成率：**已完成计划任务数 ÷ 当周应有计划任务总数。
- **首次作答正确率：**首次作答且正确的题数 ÷ 首次作答总题数（按知识点与科目分组）。
- **薄弱知识点：**近 30 天错题聚类（知识点 × 错误次数加权）+ AI 归因排序 Top 5。

**自用健康度（参考值，不设考核）：**周计划完成率中位数 ≥ 30%、复习队列日均完成 ≥ 3 项、首次作答正确率连续两周环比不降。任意一项连续 4 周不达标，回到 FR 范围与待确认项诊断。

# 非功能需求

- **性能：**主要页面首屏可交互 P95 ≤ 3 秒（常规网络）；AI 问答首字 ≤ 10 秒（P95，待 AI 接入确认）。
- **兼容：**Chrome / Edge / Safari / Firefox 最近两个大版本；移动浏览器响应式可用。
- **隐私与数据归属：**数据仅存于站长自有部署或浏览器本地；AI 调用按所选 API 政策执行，明确告知但不替 API 做承诺。
- **可用性：**核心表单支持键盘操作；颜色对比度满足正文可读。
- **成本意识：**AI 用量与成本按周统计、设置中可见（实现细节列 P1）。

# 版本规划与验证门

- **P0（MVP）：**FR-001 至 FR-014。进入条件：本评审稿获确认、待确认四项有初步结论；出口条件：连续 4 周自用健康度三项达标；止损条件：连续 4 周失败则回到定位与范围诊断，不堆功能。
- **P1 候选：**白噪音、主题皮肤扩展、知识地图可视化、AI 用量告警、OCR 题目批量导入、学习卡片分享图、移动端手势。
- **P2 候选：**语音问答、跨设备同步、AI 出题策略、模拟面试。

# 依赖与风险

| 编号 | 风险 | 等级 | 应对 |
|-|-|-|-|
