## 四、题库真题导入说明

### 4.1 可导入真题
- 目标：2023-2025 综合知识 PDF 抽取真实题目
- 结果：**PDF 文本提取不可行**
  - GitHub raw/API 下载返回 HTML 错误页（Bad request）
  - 中文字符路径导致 API 无法正常获取 blob 内容
  - LFS 大文件指针无法解析为实际内容

### 4.2 替代方案
- 题库保留 **17 个年度真题卷条目**
- 每卷包含：综合知识/案例分析/论文/详细答案 的 GitHub 网页链接
- 用户可点击链接在浏览器中下载 PDF 后自行练习
- 不做全库 OCR，不在应用中嵌入大文件

### 4.3 未来可扩展
- 若用户将 PDF 下载到本地后，可手动上传至应用
- 或提供已解析的文本/json 题库数据，可进一步导入
